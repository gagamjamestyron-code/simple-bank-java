Simple Bank

This is a small Java console app I built to practice user input, login checks, loops, and basic banking logic. It lets a user create an account, sign in, and manage a balance by checking it, depositing money, or withdrawing money.

What it does

- Creates a username and PIN
- Allows the user to log in with a limited number of attempts
- Shows a simple menu with banking options
- Checks balance
- Deposits money
- Withdraws money
- Prevents invalid or negative amounts
- Shows a goodbye message when the user exits
